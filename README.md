# loopz-ops — لوحة متابعة Loopz

لوحةٌ **خارجية** لمراقبة استقرار [loopztv.com](https://loopztv.com): المستخدمون،
أوقات الدخول، طاقةُ الخطط، والجهاتُ المرتبطة بالموقع.

## القاعدة الأولى: لا تتعارض مع تطبيق Loopz

هذا المستودع منفصلٌ عمداً عن `mccicc2-art/meshahed`. **لا ملفَّ مشترك، ولا هجرةَ
مشتركة، ولا مشروعَ Vercel مشترك.** السببُ أن إيجنتاً آخر يعمل على `meshahed`
بالتوازي، والتضاربُ الحقيقيُّ يقع في المستودع لا في المتصفّح.

ما تشاركه اللوحة مع التطبيق **شيءٌ واحد**: مشروع Supabase نفسه، **قراءةً فقط**،
عبر دوالَّ مسبوقةٍ بـ`ops_`.

الضماناتُ المكتوبة في `sql/ops_01_functions.sql`:

| الضمانة | لماذا |
|---|---|
| لا جدولَ جديداً في `public` | لا يظهر شيءٌ في مخطّط التطبيق |
| **لا سياسةَ RLS واحدة** | فحصُ الصحّة عند الإيجنت الآخر يتوقّع **أربع** سياساتٍ مفتوحة بالضبط؛ الخامسةُ تكسره |
| قراءةٌ فقط — لا `insert`/`update`/`delete` | لا يمكن للوحة أن تُفسد بيانات |
| بادئة `ops_` على كلِّ دالّة | المالكُ معروفٌ من الاسم |
| أعدادٌ مجمَّعة فقط | لا إيميل، لا اسم، لا IP يغادر القاعدة |
| جدولُ اللقطات في سكيما `ops` | غيرُ معروضٍ في PostgREST، لا يصله `anon` |

## التشغيل

### ١. SQL (مرّة واحدة)
شغّل `sql/ops_01_functions.sql` في محرّر SQL في لوحة Supabase.
الناتجُ المتوقّع: `Success. No rows returned`.

> ملاحظةٌ لمحرّر Supabase: يستغرق ٢٥–٦٠ ثانية ليُقلع، وقد يعلق فارغاً.
> الحلُّ تبويبٌ جديد لا انتظارٌ أطول.

### ٢. متغيّرات البيئة في Vercel

| المتغيّر | مطلوب | ماذا يفتح |
|---|---|---|
| `SUPABASE_URL` | ✅ | `https://uvgmvrdrxzpudoldjxaa.supabase.co` |
| `SUPABASE_ANON_KEY` | ✅ | المفتاحُ المجهول — عامٌّ بحكم التصميم، ويبقى على الخادم (بلا `NEXT_PUBLIC_`) |
| `VERCEL_TOKEN` | ⬜ | الباندويث والدوال والنشرات |
| `GITHUB_TOKEN` | ⬜ | يرفع حصّة GitHub من ٦٠ إلى ٥٠٠٠ نداء/ساعة |
| `OPS_KEY` | ⬜ | يُفعَّل مع `sql/ops_02_lockdown.sql` |

**ما لم يُضبط لا يُخمَّن.** كلُّ مصدرٍ ناقصٍ يظهر في اللوحة بسبب فقدانه
وبالخطوة التي تُصلحه، ولا يظهر صفراً.

### ٣. الحماية
`Settings → Deployment Protection`. اللوحة تعرض أرقاماً داخلية،
ولا يجوز أن تُفتح بلا حماية.

## أين تُقاس الحدود
كلُّ الحدود والخطط في `src/lib/config.ts` وحده. تغيّرت خطّة؟ يُعدَّل الملفُّ
هذا ولا شيءَ غيره.

## المصادر
- **Supabase** — دوالُّ `ops_*`.
- **GitHub** — الواجهةُ العامّة (بلا توكن).
- **الموقعُ الحيّ** — `loopztv.com/api/build` مقابل رأس `main`. هذا **أهمُّ فحص**:
  نشراتُ Vercel تنتهي خارج الترتيب فتبقى نشرةٌ أقدمُ إنتاجاً، و«READY» لا تكشفه.
- **Vercel** — عند وجود التوكن فقط.

## ما لا تعرفه اللوحة
مكتوبٌ في آخر بطاقةٍ في الصفحة نفسها. الفراغُ يُقال ولا يُملأ.
